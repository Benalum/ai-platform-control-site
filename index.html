Backend contract

Designed to be reusable for other programs later.

1. Browser submits

The page sends a structured JSON request to your API. Later, you can reuse the same flow for video, audio, chat, file processing, or other tools.

2. API controls wake

Your backend checks if the server is online. If not, it wakes the machine using safe server-side logic such as WOL, Tailscale, router tools, or Proxmox automation.

3. Queue handles jobs

The backend writes the request into a queue. A worker then sends it to ComfyUI when resources are available.
